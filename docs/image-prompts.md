# Picture prompts for Smallfold

Paste each prompt into an image generator. Every prompt is complete by itself.
Generate each picture in the shape given, at the largest size the tool offers.

These prompts were used on 21 November 2026 to generate the pictures now on the site, with the
Soul 2.0 model in Higgsfield. Use them again to make replacements in the same style. That model
offers 3:4 instead of 4:5 and 16:9 instead of 2:1; the pictures are cropped when they are placed.

## How to send the finished pictures

1. Save each picture as a JPG or PNG. Any file name is fine, but naming them after the slot
   (`hero`, `band`, `difference-1` and so on) saves a step.
2. On GitHub, open the repository, switch to the branch `claude/awesome-lamport-rlk8gy`,
   choose **Add file → Upload files**, and upload them into a folder named `incoming-photos`.
3. Say they are there. They are then cropped to the exact sizes, compressed, given a smaller
   copy for phones and a description, and placed on the site.

## What makes a picture work on this site

- **One series.** Use the same style sentence at the end of every prompt, so the pictures look
  like one shoot.
- **No readable text, logos or brand names** anywhere, and no recognisable app or website on a screen.
- **Faces turned away.** People are seen from behind, from the side, or as hands. A generated
  face can look artificial, and a clear face reads as a real client.
- **Calm, dark middle on the two home-page pictures** (`hero`, `band`): a headline sits on top of them.
- If a result has garbled text, extra fingers or a logo, generate it again.

Editorial photograph, 35mm film, warm low-key window light, deep soft shadows, muted palette of charcoal, taupe and warm cream, shallow depth of field, fine film grain, quiet mood.
