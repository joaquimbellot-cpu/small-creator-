## Needs another agent
- FC: `SendBar.tsx` should show the server's message when the answer has `reason: 'sent_not_recorded'` (HTTP 409, JSON `{error, reason}`) and stop the run, so nobody sends again. Today it only counts a failure.
- FC: the Overview must show the notice for `/overview?notice=owner-only`; the main navigation must link workers to /settings/security. e2e-auth.cjs now expects no header link to /settings/users, /audit or /sending for a worker.
- Not mine, for the owner of lib/supabase/browser.ts: the cookie that /auth/hash creates in the browser is written by the browser client and is not httpOnly. It is replaced by an httpOnly one the next time the server refreshes the session. Low impact (short recovery link).
- Netlify: set `ASSISTANT_DEADLINE_MS=50000` as the old comment says; `maxDuration = 30` only counts where the host honours it.
- FA: `release_stale_sending(p_minutes integer)`, `reset_allowed(email, ip)`, `record_reset_request(email, ip)` are called by name; parameter names `p_minutes`, `email`, `ip` must match.
