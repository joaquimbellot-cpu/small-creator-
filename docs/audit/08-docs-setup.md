# Docs and setup audit (agent 8)

## 1. Scope and method

- Question: could a new person run Smallfold from scratch using only the READMEs?
- Read: `admin/README.md`, `README.md`, `docs/handoff.md`, all of `admin/dev/` (start, stop, reset, migrate, lib, keys, gateway, mail catcher), `admin/supabase/seed/`, `admin/supabase/tests/`, `admin/tests/run-all.sh`, `admin/.env.example`, `netlify.toml`, `admin/package.json`, and the app, lib and test files that read `process.env`.
- Ran (read-only or in scratch): `node build.js --out <scratch>` and `node build.js --self-test` (24 cases passed). The scratch build matched the committed `site/` folder exactly.
- Checked `admin/.env.local` by name only, plus two match counts (`SMTP_HOST` is `localhost`, `SMTP_PORT` is `1025`). No values were printed.
- Did not run `start.sh`, `stop.sh`, `reset.sh`, any test suite, `npm run build`, or any live or connector service.

## 2. Done well

- The migration list in `admin/README.md` (lines 132-142) matches the 11 files in `admin/supabase/migrations/` exactly, in order.
- `admin/.env.example` covers every `process.env` name the app reads, and the defaults it describes match the code (model names, `ASSISTANT_DAILY_LIMIT` 100, `ASSISTANT_DEADLINE_MS` 270000 with values under 15000 ignored, mock drafting when there is no key).
- The safety figures in the README match the database: 30 emails a day (`20261121000200_tables.sql:114`), 5 seconds between sends (`:115`), 5 website forms an hour (`20261122000900_website_forms.sql:63`), 12 steps and 100 messages a day for Claude, and `noindex` in `src/partials/head.html:6`.
- The local scripts are careful. `stop.sh` keeps data, `reset.sh` says what it wipes, `keys.mjs` keeps lines it does not manage, and `lib/email/e2e.cjs:16` refuses to run unless SMTP points at the local catcher.
- `ANTHROPIC_BASE_URL` is described correctly. The SDK reads it itself (`node_modules/@anthropic-ai/sdk/client.js:104`).
- `docs/handoff.md` gives dated live facts and checks, and says what is still to do.
- The main README's commands, flags, file list and content file names match `build.js` and `src/`.
