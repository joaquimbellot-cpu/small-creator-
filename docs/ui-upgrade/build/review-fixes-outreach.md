# Review fixes: outreach and drafting (fix agent B)

- SR-04: `lib/drafting/pitch-safety.ts` (new) cleans every stranger-controlled value before it reaches the prompt: control and hidden characters, brackets, line breaks, length caps (names 80, industry 60, free-text niche 40 and letters/digits/&/- only), first names letters only (40), channel link must be http(s) without credentials. A past sponsor, channel name or industry that holds an email address, link, domain, phone number or instruction-like wording is left out; if the pitched sponsor's own name is like that, `buildPitchFacts` returns `blocked` and no draft is written. Facts sit inside `<untrusted_facts>`; the system prompt says it is data only and asks for names exactly as given. The validator checks the whole draft (before any name is removed) for `@`, any web address or bare domain other than the channel link, and phone-like numbers, then fee/rate/pay/earn/revenue words.
- Capital-word check: a capitalised word at the start of a sentence must be a common starter, a word from the facts, or a word the draft also writes in lower case; otherwise it is a suspect name. "1M" style suffixes are no longer read as names.
- B-5 cause: the target size "1M"/"1.5M" in the practice draft was read as a company called "M" (any sponsor whose target size reached a million). C-3: the mock rewritten so no sentence starts with a name or lower case.
- SR-08 (emails screens): Review and the email detail page write `contact.viewed` (contact address) or `creator.viewed` (creator address) with entity type `email`, once per view, after the response, skipping prefetch and own-action refreshes. The log page shows no address. Belongs to others: SR-08 (a) and (b) in `SponsorProfile.tsx`; the audit screen label for `contact.viewed` says "Viewed an Inbox message" (`settings/audit/format.ts`).
- SR-13: one line on the Review card and the email detail page: an opt-out by that person blocks that address only.
- Tests: `lib/drafting/pitch.safety.test.ts` (18 clean and 30 bad drafts, hostile names, B-5 names of 16 shapes in both directions, C-3 over 512 fact combinations).
